Manafall cloud-agent playtest source patch

  git apply --check Docs/Playtest/manafall_cloud_agent_full.patch
  git apply Docs/Playtest/manafall_cloud_agent_full.patch

Or code-only:

  git apply Docs/Playtest/manafall_cloud_agent_code.patch

  git apply Docs/Playtest/manafall_version_label_and_hide_debug.patch

After apply, rebuild the Windows client in Unity. Main menu bottom-left shows vX.Y.Z
(Application.version). Current source identity is 0.1.44. In-game auto-patch on the
website is still 0.1.43 until a new Windows release is published.
