Manafall cloud-agent playtest source patch
==========================================
Apply onto a clean checkout of main:

  git apply --check Docs/Playtest/manafall_cloud_agent_full.patch
  git apply Docs/Playtest/manafall_cloud_agent_full.patch

Or use the code-only patch (smaller, skips most binary assets):

  git apply Docs/Playtest/manafall_cloud_agent_code.patch

Debug-overlays-only (tiny):

  git apply Docs/Playtest/manafall_hide_debug_overlays.patch

Includes: filament water caustics, hide sticky F3/F4 debug overlays in player builds,
and other PR #76 work. Not a Windows game zip — rebuild the client in Unity after apply.
