Build with us

Manafall needs collaborators. This is unpaid. You get a credit in the game and one system you can show. A few hours a week. Adults. Jean-Luc Alexander stays the owner. There is no salary and no promise of a cut of sales.

  • Unity gameplay, Mirror. First task is one multiplayer fix, with a clip before and after. You have shipped a small Unity multiplayer scene.
  • World art. First task is one prop or building piece that sits in the existing world. You have a model that can drop into Unity.
  • Lore and dialogue. First task is one NPC conversation in the voice the game already uses. You read the existing lore before you write.

Play the Windows build first. Then come to Discord and say which seat you want, what you have shipped, and how many hours you can give this month.
