TikTok integration demo

Content Studio

First-party publishing for the official Manafall TikTok (@manafalltiktoc). This page demonstrates Login Kit and Content Posting API (user.info.basic, video.publish) on the Manafall website domain.

1. Setup (Sandbox)

Use your TikTok Developer Portal Sandbox client key. Redirect URI must be registered exactly:

https://jla1190.github.io/manafall-website/content-studio/callback.html

2. Login Kit

Authorize @manafalltiktoc (or your Sandbox target user). Scopes requested: user.info.basic, video.publish.

Not connected 

    


    

      
3. Access token (Sandbox)

      
Paste your access_token (starts with act.). TikTok blocks the browser from calling their API directly, so you must also run the local helper on your PC.

      
In PowerShell:

      cd C:\Manafall\_manafall-website\content-studio
powershell -ExecutionPolicy Bypass -File .\tiktok-local-proxy.ps1
      
Local helper: checking…

      
      
      
      

    


    

      
4. Content Posting API

      
Direct Post init with FILE_UPLOAD, then upload the video bytes. Unaudited/sandbox posts may be private-only.
